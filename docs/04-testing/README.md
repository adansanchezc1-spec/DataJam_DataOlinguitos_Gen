# Fase 04 — Aseguramiento de Calidad y Pruebas Unitarias (CONTROL)

**Fase PDCO**: CONTROL | **SDLC Stage**: Software Testing & Quality Assurance  
**Estándares**: SWEBOK Cap. 5, IEEE 829 / ISO 29119, ISO/IEC 25010, pytest 8.0+  

---

## 🧪 Propósito de la Fase

Esta fase establece el marco de verificación y validación (V&V) del sistema, planes de prueba estructurados bajo el patrón AAA (Arrange-Act-Assert), cobertura de código y reporte de resultados de las suites automatizadas.
