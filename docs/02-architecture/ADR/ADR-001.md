# ADR-001: Adopción de Arquitectura Hexagonal y Pipeline Modular
**Fecha**: 2026-08-18 | **Estado**: Aceptado  
**Contexto**: Se requería una estructura de código que permitiera la ejecución reproducible desde notebooks interactivos y scripts CLI automatizados.  
**Decisión**: Implementar el core analítico en módulos reutilizables `src/` y consumir dichos módulos desde notebooks (`notebooks/`) y pruebas unitarias (`tests/`).  
**Consecuencias**: Alta testabilidad (>90% de cobertura), cero duplicación de código y fácil mantenimiento.
