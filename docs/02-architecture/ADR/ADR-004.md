# ADR-004: Adopción de Remuestreo Bootstrap Dirichlet y Control de Multicolinealidad (VIF)

**Fecha**: 2026-08-23 | **Estado**: Aceptado  
**Fase PDCO**: CONTROL → OPERATIONS  
**Estándar**: American Statistical Association (ASA), SWEBOK Cap. 4  

## Contexto
Los modelos compuestos son susceptibles a incertidumbre por variaciones en las ponderaciones subjetivas y a redundancia dimensional por colinealidad inadvertida entre indicadores.

## Decisión
1. Implementar la prueba del **Factor de Inflación de la Varianza ($\text{VIF}_j$)** con un umbral de aceptación estricto $\text{VIF} < 10.0$.
2. Implementar remuestreo no paramétrico **Bootstrap Dirichlet ($B = 1.000$ réplicas)** para generar intervalos de confianza empíricos al $95\%$ ($\text{IC}_{95\%}$) para cada localidad.

## Consecuencias
- **Positivas**: Certificación computacional de no redundancia ($\overline{\text{VIF}} = 3.21$). Asignación de niveles de confianza robustos para el Top 5 prioritario.
- **Trade-offs**: Incorporación de pruebas estadísticas automatizadas en `tests/test_statistical_rigor.py`.
