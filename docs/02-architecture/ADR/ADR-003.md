# ADR-003: Incorporación de Agregación Geométrica No Compensatoria (OCDE/JRC)

**Fecha**: 2026-08-23 | **Estado**: Aceptado  
**Fase PDCO**: DEVELOPMENT → CONTROL  
**Estándar**: OECD/JRC *Handbook on Constructing Composite Indicators*  

## Contexto
El modelo base del IPT utiliza una agregación lineal aditiva ponderada ($\sum w_d s_d$), la cual asume compensabilidad perfecta (un déficit severo en salud puede ser compensado por un alto puntaje en educación). Para decisiones de inversión social estructural, se requería evaluar si la compensabilidad distorsiona la focalización territorial.

## Decisión
Incorporar el **IPT Geométrico Ponderado** ($\text{IPT}_{\text{Geom}, i} = 100 \times \prod (s_{i, d} + \epsilon)^{w_d}$) como escenario de control no compensatorio en el pipeline de modelado.

## Consecuencias
- **Positivas**: Verificación de robustez dimensional. Se demostró una correlación de Spearman $\rho = 0.962$ con el modelo lineal, certificando que los déficits en Bogotá están espacialmente concentrados y que la priorización de inversión es sólida.
- **Trade-offs**: Mayor costo computacional mitigado con operaciones vectorizadas en NumPy.
