# ADR-002: Definición del Índice de Prioridad Territorial (IPT) Multidimensional
**Fecha**: 2026-08-18 | **Estado**: Aceptado  
**Contexto**: Medir las brechas territoriales requería un indicador sintético que integrara servicios públicos, conmutación laboral, informalidad, salud, educación y seguridad.  
**Decisión**: Utilizar normalización Min-Max [0, 1] con ponderación multicriterio de 7 dimensiones teóricas escaladas a un rango de 0 a 100 puntos.  
**Consecuencias**: Ranking comprensible y transparente para la toma de decisiones distritales.
